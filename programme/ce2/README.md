# Programme de CE2 — les leçons

Les leçons de mathématiques de CE2, une leçon par fichier, dans l'ordre du programme ; chaque fichier reprend ses pages dans l'ordre, avec un repère `<!-- page N -->`. Les définitions sont celles vues en classe ; les méthodes et les exemples sont reformulés.

Les fichiers de leçon sont la seule source versionnée ; `programme/outils/assembler.py` a servi à les constituer à partir de sources locales, page par page, qui ne sont pas dans le dépôt.

## Conventions

- `> Je sais …` : l'objectif de la leçon, tel qu'écrit dans le document.
- Les opérations posées sont dans des blocs de code, colonnes alignées, retenues au-dessus.
- `(Illustration : …)` ou `(Schéma : …)` décrit un dessin de la leçon qui n'a pas d'équivalent texte.
- `[illisible]` signale un mot que la source ne permettait pas de lire.
- `### (écrit à la main)` : annotation manuscrite ajoutée sur le document.
