# Programme de CE2 — transcription du livret de leçons

Transcription en Markdown du livret de leçons de mathématiques utilisé en classe, à partir de photos des pages. Une leçon = un fichier ; chaque fichier reprend ses pages dans l'ordre, avec un repère `<!-- page N · photo … -->` au début de chaque page pour pouvoir revenir à la photo d'origine.

Les photos elles-mêmes ne sont pas dans le dépôt. Les transcriptions brutes, photo par photo, sont dans `_transcriptions/` ; ce README et les fichiers de leçon sont régénérés par `programme/outils/assembler.py`.

## Conventions

- `> Je sais …` : l'objectif de la leçon, tel qu'écrit dans le livret.
- Les opérations posées sont dans des blocs de code, colonnes alignées, retenues au-dessus.
- `(Illustration : …)` ou `(Schéma : …)` décrit un dessin du livret qui n'a pas d'équivalent texte.
- `[illisible]` signale un mot que la photo ne permettait pas de lire.
- `### (écrit à la main)` : annotation manuscrite ajoutée sur le livret.
